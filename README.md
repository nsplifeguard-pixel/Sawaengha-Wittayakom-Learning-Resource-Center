# ศูนย์แหล่งเรียนรู้ โรงเรียนแสวงหาวิทยาคม

ชุดต้นแบบระบบแบบ Modular จำนวนหลายไฟล์ สำหรับนำไปพัฒนาต่อเป็น Web App จริง

## โมดูล
1. Dashboard
2. แหล่งเรียนรู้
3. QR Code
4. กิจกรรม
5. นักเรียน
6. ครู/บุคลากร
7. แบบทดสอบ
8. คะแนน/Badge
9. การยืมสื่อ
10. ข่าวสาร
11. ปฏิทิน
12. แผนที่
13. รายงาน
14. ตั้งค่า
15. Backup/Restore
16. สิทธิ์ผู้ใช้งาน

## การทดลอง
เปิด `index.html` หรือ `login.html` ด้วยเว็บเบราว์เซอร์
ข้อมูลตัวอย่างถูกเก็บใน LocalStorage

## การเชื่อมต่อจริง
สามารถเปลี่ยน Data Service ไปใช้ Google Sheets/AppSheet, Firebase หรือ Supabase ได้
